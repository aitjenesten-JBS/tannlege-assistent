# Tannlege-assistent

Digital assistent for en norsk tannklinikk. Assistenten svarer på praktiske spørsmål, og bestiller, flytter og avbestiller timer i en simulert timebok. Bestillingene sendes videre til klinikkens system for gjennomgang.

> Porteføljeprosjekt og demo. Ikke tilknyttet noen klinikk. Ingen ekte pasientdata.

<!-- GIF: booking fra start til bekreftelse -->

## Problemet

«Bestill time» på klinikkens nettside er i dag et skjema: pasienten sender en forespørsel, og noen må ringe tilbake. Klinikken har bare åpent hverdager 08–16, så henvendelser som kommer om kvelden og i helgen, blir liggende. Målet er at pasienten får svar og en bekreftet time med en gang, døgnet rundt, og at klinikken får færre telefoner om ting som allerede står på nettsiden.
